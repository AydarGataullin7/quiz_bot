# Quiz Bot

Telegram и VK боты для викторины с вопросами и ответами.

## Возможности

- Случайные вопросы из базы данных
- Клавиатура с кнопками: `"Новый вопрос"`, `"Сдаться"`, `"Мой счет"`
- Подсчет правильных ответов
- `Redis` для хранения состояния пользователей
- Поддержка `Telegram` и `ВКонтакте`

## Технологии

- `Python 3`
- `Redis`
- `Telegram Bot API`
- `VK API`
- `python-telegram-bot`
- `vk_api`

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/AydarGataullin7/quiz_bot.git
cd quiz_bot
```
### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```
### 3. Настройка переменных окружения
Создайте файл `.env` в корневой папке проекта:

```env
TG_TOKEN=ваш_токен_телеграм_бота
VK_TOKEN=ваш_токен_группы_вконтакте
```
### 4. Запуск Redis
Убедитесь, что Redis запущен локально:
```bash
redis-server
```
### 5. Запуск бота
Для Telegram:
```bash
python tg_bot.py
```
Для ВКонтакте:
```bash
python vk_bot.py
```
## Как пользоваться
Начните общение с ботом командой `/start` (Telegram) или `Начать` (VK)

Нажмите `"Новый вопрос"` для получения случайного вопроса

Напишите свой ответ

Получите обратную связь: правильно или неправильно

Используйте `"Сдаться"` для просмотра правильного ответа

Проверьте свой счет через `"Мой счет"`
